# Phase 2 baseline

This directory freezes the lightweight outputs from the five-state 2024
prototype with configuration digest `365b9697fd28`.

The original run remains under:

`results/prototype/year=2024/run=365b9697fd28/`

`SHA256SUMS` verifies the exact configuration and output files. Raw BRFSS data,
the harmonized respondent-level file, and serialized per-population graphs are
not versioned here.

The PNG checksum is archival provenance only. Automated regression tests use
the scientific tables and configuration digest, not renderer-dependent image
bytes.
